# TFG

Aquest repositori conté el treball de recerca i el desenvolupament tècnic del Treball de Final de Grau, realitzat durant el curs acadèmic 2025-2026, titulat: "Anàlisi i segmentació de clients a la província de Barcelona a partir de l’enquesta d’hàbits de consum i compra".

L'objectiu principal és identificar patrons de comportament i perfils de consumidors mitjançant *Latent Class Analisys* (LCA), proporcionant una visió detallada de la realitat del consum a l'àrea de Barcelona.

## 📂 Contingut del repositori

## 📊 Resultats Destacats

L'anàlisi mitjançant Latent Class Analysis (LCA) ha permès identificar tres perfils de consumidors a la província de Barcelona, diferenciats pels seus valors i nivell d'exigència, més que no pas per la seva despesa econòmica:

* Classe 1 (Distant/Desconnectat): Segment majoritàriament femení i envellit (+65 anys) amb baixa vinculació amb els atributs de valor afegit i el canal digital.

* Classe 2 (Conscient/Premium): Consumidor molt informat i digitalment actiu que prioritza l'excel·lència en productes de proximitat, artesania i venda directa.

* Classe 3 (Pragmàtic): El perfil majoritari del mercat; valora la sostenibilitat i el comerç just, però amb una alta sensibilitat al preu i un enfocament pràctic.

Mencionar també que els valors (ecologia, proximitat, comerç just) són els veritables motors de segmentació i que el volum de despesa mensual no és un factor diferenciador entre els grups identificats.
